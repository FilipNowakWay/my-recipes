# 🍲 My Recipes

Welcome to **My Recipes**, my very first HTML project built as part of [The Odin Project](https://www.theodinproject.com/) Web Development curriculum!

This project is a simple, static recipe website designed to practice foundational HTML skills, structure a multi-page website, and manage version control using Git.

[HERE!](https://filipnowakway.github.io/my-recipes/)

## 🛠️ Built With

- **HTML5** – For structuring the content and semantic layout.
- **Git & GitHub** – For version control, tracking changes, and hosting the repository.
- **Neovim** – As the primary text editor for writing and managing code.
